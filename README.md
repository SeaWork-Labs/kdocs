# 金山文档

金山文档官方技能：新建与编辑文档、表格、演示、智能表格，知识归档、接龙转表格、文档转 Markdown、表单生成，全程对话完成。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/kdocs#v1.3.7 --skill kdocs
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill kdocs
```

## 内容

技能正文在 `skills/kdocs/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/kdocs/payload/`，不要反向同步。版本以 git tag 为准。
